# React Profile Cards

An early React exercise in reusable profile-card components and props.

The application renders profile information through a small card component and uses Bulma styling. The name reflects the original exercise; this is not a conversational or automated personal assistant.

## Start reading

- [`src/App.jsx`](src/App.jsx)
- [`index.html`](index.html)

## Development

Use Node.js and npm compatible with the versions recorded in the package manifest and lockfile. Each package is installed from its own directory.

From the repository root:

```sh
npm ci
npm start
```

Additional scripts in this package: `npm run build`.
